# 🚆 SARATHI

> A Railway Route Planning and Navigation System built with Spring Boot.

SARATHI is a backend application that helps users find railway routes between stations using graph algorithms. It provides secure authentication using JWT and manages railway regions, stations, and their connections.

---

## ✨ Features

- 🔐 User Registration & Login
- 🔑 JWT Authentication & Authorization
- 👤 Role-Based Access Control
- 🚉 Railway Station Management
- 🗺️ Railway Region Management
- 🔗 Station-to-Station Mapping
- 📍 Shortest Route Calculation
- 📏 Distance-Based Path Finding
- 🛡️ Spring Security Integration
- 🗄️ MySQL Database Support
- 📦 RESTful APIs
